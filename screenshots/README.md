# Screenshots

Bureau's screenshots and its new-tab artwork were removed with the rebrand —
they showed Bureau's identity and were Sonophage's work to present.

Afterimage's own captures come from the repository's disposable test vault,
never from Mike's real notes:

```bash
npm run preview          # serve the repo on :8817
npm run shots            # render the DOM-harness captures
```

`screenshot.png` (the card a theme gallery would show) must be a real Obsidian
capture at 1920×1080 or larger. `docs/TESTING.md` records exactly what has and
has not been verified inside Obsidian itself.
